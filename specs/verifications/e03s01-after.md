  that is deliberately not committed, because the README makes this file the source of truth.

  no tags.

## What the run corrected

1. **The vendored images are not unused.** The story's plan was to delete them and test the vendoring
   rule synthetically. Two browser tests falsified that on the first full run: `LAYOUT-08`
   (*a photographed product stays inside its picture*) and `UI-06` (*product images are local*) both
   need at least one real photograph. The five files were restored, rewired to new SKUs, and now
   exercise the rule against the real catalogue — with a synthetic case beside them.
2. **The tags were not a usable vocabulary.** The new API-31 assertion failed on the first run:
   tags were `FHD`, `4K`, `60Hz`, so a criterion written as `tag:4k` would never have matched. Tags
   are now lower case and hyphenated; attribute keys were already well formed.
3. **Metadata is required, so every test fixture had to say so.** Roughly 20 fixture rows across five
   test projects were refused until they carried metadata. That is the intended behaviour — a row
   without it cannot be matched against — but it is the reason this story touches so many files.
4. **Two hard-coded SKUs and eleven hard-coded counts** in the suites pointed at the old catalogue
   (`CHA449AGLBB0`, `MONJVAP81NPQ`, 62, 10, 42, 6, 8) and were rewritten.
5. **One browser test was waiting on the wrong thing.** `WS-02` waited for `Seminyak Lounge` to leave
   the chair slot; with the catalogue renamed, that assertion was satisfied before the click was even
   handled, so the test read the slot too early. It now waits for the second product to arrive.

## Not done, deliberately

- **No criteria-token resolver type.** The plan called for one; nothing in this epic resolves a token,
  so the vocabulary is asserted rather than implemented. The resolver belongs with its first caller.
- **No change to `Search`.** The store's name-only search, `API-05` and the browser search tests are
  untouched; the new tags are matched by the agent, not by the store.
- **No embeddings, index or vector store**, per the scope's trigger conditions.
