# Rephraser Case Matrix

Machine-readable matrix:

```text
specs/evaluation/rephraser/REPHRASER_CASE_MATRIX.csv
specs/evaluation/rephraser/REPHRASER_TERM_MATCHES.csv
```

The matrix covers the 100 half-scope cases from the current run and records pass, timeout, expected SKUs, actual SKUs, last stage, judge result, and failure codes. The term matches record every emitted rephraser term and whether it matched the expected product's name, description, or tags.
